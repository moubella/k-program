# K Program Gym App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A tiny offline web app, saved to an iPhone home screen, that shows a beginner which of 3 gym sessions (A → B → C) to do next and exactly what to do in it, with the right sets and cardio minutes for the current program week.

**Architecture:** Static files only. `program.json` holds the whole program; small ES modules hold pure logic (`schedule.js`: weeks, phases, rotation, dates; `storage.js`: last finished session; `render.js`: HTML strings for the two screens) and are unit-tested with Node's built-in test runner; `app.js` wires them to the DOM with hash routing. A service worker makes it work offline.

**Tech Stack:** Plain HTML, CSS, JavaScript (ES modules), no framework, no build step, no runtime dependencies. Tests: `node --test` (Node 24, `node:test` + `node:assert/strict`). Icons: macOS `sips`.

**Spec:** `docs/superpowers/specs/2026-11-17-gym-app-design.md`

## Global Constraints

- No framework, no build step, no runtime dependencies; `package.json` exists only to set `"type": "module"` and the test script.
- All URLs relative (`./program.json`, `js/app.js`, `icons/…`) so the app works when hosted under a sub-path such as `/k-program/`.
- All text in English. Use the en dash `–` in ranges (`10–12`, `20–30 s`), `×` for sets × reps, `·` as separator, exactly as in the spec.
- The only thing stored on the phone is the last finished session (`{ sessionId, date }`) under the local-storage key `kprogram.lastDone`.
- Week = full 7-day blocks since `startDate` + 1, from the phone's local date; a future start date shows week 1.
- Mobile first: tap targets at least 44 px tall, body text at least 17 px, follows light/dark mode via `prefers-color-scheme`.
- Commit **and push** after every task, using the repo's emoji commit style (`<emoji> <Active-voice sentence>`, no trailers).

## Review Focus

- Start date in the future (she opens the app before her first session) → "Week 1", 2 sets, 10 min cardio. Pinned in Task 2.
- A daylight-saving change between the start date and today (Europe: 29 Mar, 25 Oct) → the week number does not shift by a day. Pinned in Task 2.
- Local storage blocked, empty, or holding garbage (private mode, cleared site data) → A is "Next up", no crash. Pinned in Task 3.
- Stored last session id no longer exists after a program edit → the first session is "Next up". Pinned in Task 2.
- Hosted under a sub-path and opened offline → every URL is relative and every file the page loads is in the service-worker cache list. Pinned in Task 6.
